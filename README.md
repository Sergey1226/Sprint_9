# Sprint 9: Автоматизация тестирования Foodgram

## Описание
Автоматизированные тесты для сервиса "Продуктовый помощник" с использованием Selenium, Page Object Pattern и Docker.

## Структура проекта
- `tests/` - тесты (регистрация, авторизация, создание рецепта)
- `pages/` - Page Objects
- `locators/` - локаторы элементов
- `helpers/` - тестовые данные и конфигурация
- `assets/` - тестовые файлы (изображения)

## Запуск тестов

### Локально
```bash
pip install -r requirements.txt
pytest tests/ -v
